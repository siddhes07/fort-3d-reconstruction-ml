%============================================
\subsection{Variables}

\textbf{What is it?} \\
A variable is a name we give to a piece of data so we can store and refer to it later. In Python, we do not need to declare the type of a variable beforehand -- Python figures out the type automatically based on the value assigned.

\textbf{Why do we need it?} \\
While a program runs, we often need to hold on to values -- numbers, text, results of calculations -- and reuse them later. Without variables, every value would have to be typed out again and again, which is impractical. Variables let us give data a name and access or update it whenever needed.

\textbf{Where and How is it used?} \\
Variables are used everywhere data needs to be held temporarily -- in calculations, storing user input, loop counters, or saving the result of a function.
\begin{lstlisting}
age = 21
name = "Siddhesh"
price = 99.5
\end{lstlisting}
Here \texttt{age}, \texttt{name}, and \texttt{price} are variables holding an integer, a string, and a float value respectively.

%============================================
\subsection{Basic Data Types}

\textbf{What is it?} \\
A data type is a label that tells Python what kind of value a variable is holding. Python has several built-in data types, four of which are covered below.

\textbf{Why do we need it?} \\
The data type tells Python which operations are valid on a value (for example, addition works on numbers, concatenation works on strings). Using the wrong type for an operation leads to errors or incorrect results.

\textbf{Where and How is it used?} \\
Every variable has a type, which Python detects automatically (dynamic typing):
\begin{lstlisting}
count = 5           # Integer
price = 99.5         # Float
is_active = True     # Boolean
name = "Siddhesh"    # String
\end{lstlisting}

\subsubsection*{Integer}
An integer is a whole number -- positive, negative, or zero -- with no decimal point. It is used for counting, indexing, and loop iterations.

\subsubsection*{Float}
A float is a number with a decimal point (e.g. 3.14). It is used for measurements, prices, and calculations that need precision.

\subsubsection*{Boolean}
A boolean can only take two values: \texttt{True} or \texttt{False}. It is used to check conditions in \texttt{if}-\texttt{else} statements and loops.

\subsubsection*{String}
A string is a sequence of characters (text data), written inside single or double quotes. It is used to represent names, messages, and file contents.

%============================================
\subsection{Arithmetic Operators}

\textbf{What is it?} \\
Arithmetic operators are symbols used to perform mathematical calculations -- such as \texttt{+, -, *, /, \%, **, //}.

\textbf{Why do we need it?} \\
Any numerical calculation, from simple addition to computing averages, needs these operators. Without them a program could not process numbers at all.

\textbf{Where and How is it used?} \\
They are used everywhere from billing systems to statistics to game scoring:
\begin{lstlisting}
a = 10
b = 3
print(a + b)   # addition -> 13
print(a - b)   # subtraction -> 7
print(a * b)   # multiplication -> 30
print(a / b)   # division -> 3.333...
print(a % b)   # modulus (remainder) -> 1
print(a ** b)  # power -> 1000
print(a // b)  # floor division -> 3
\end{lstlisting}

%============================================
\subsection{Comparison Operators}

\textbf{What is it?} \\
Comparison operators compare two values and return \texttt{True} or \texttt{False} -- such as \texttt{==, !=, >, <, >=, <=}.

\textbf{Why do we need it?} \\
Decision making -- in \texttt{if}-\texttt{else} conditions and loop termination -- requires comparing values against each other.

\textbf{Where and How is it used?} \\
Used inside conditions and loops:
\begin{lstlisting}
x = 5
y = 10
print(x == y)   # False
print(x != y)   # True
print(x < y)    # True
print(x >= y)   # False
\end{lstlisting}

%============================================
\subsection{Assignment Operators}

\textbf{What is it?} \\
Assignment operators are used to assign values to a variable -- such as \texttt{=, +=, -=, *=, /=}.

\textbf{Why do we need it?} \\
They give a shorthand way to update the existing value of a variable, making code shorter and more readable.

\textbf{Where and How is it used?} \\
Used for updating counters and maintaining running totals:
\begin{lstlisting}
count = 5
count += 1   # count = count + 1 -> 6
count -= 2   # count = count - 2 -> 4
count *= 3   # count = count * 3 -> 12
\end{lstlisting}

%============================================
\subsection{Type Conversion}

\textbf{What is it?} \\
Type conversion means converting a value from one data type to another (e.g. string to integer).

\textbf{Why do we need it?} \\
User input often arrives as a string (for example, from \texttt{input()}), but a mathematical operation needs a numeric type. Conversion is required to bridge this gap.

\textbf{Where and How is it used?} \\
Done using built-in functions: \texttt{int(), float(), str(), bool()}
\begin{lstlisting}
age_str = "21"
age_int = int(age_str)   # string -> integer
price = str(99.5)        # float -> string
\end{lstlisting}

%============================================
\subsection{Input and Output}

\textbf{What is it?} \\
Input means receiving data from the user, and output means displaying results on the screen. Python provides \texttt{input()} and \texttt{print()} for this.

\textbf{Why do we need it?} \\
To make a program interactive, it must be able to take data from the user and show results back; otherwise the program would only work on fixed, hardcoded values.

\textbf{Where and How is it used?} \\
Used in forms, calculators, and virtually all interactive programs:
\begin{lstlisting}
name = input("Enter your name: ")  # input from user
print("Hello", name)               # output display
\end{lstlisting}
Note: \texttt{input()} always returns a string, so it must be converted if a different type is needed.

%============================================
\subsection{Strings}

\textbf{What is it?} \\
A string is an ordered sequence of characters, written inside quotes (\texttt{"text"} or \texttt{'text'}).

\textbf{Why do we need it?} \\
Strings are needed to represent text-based data such as names, messages, and file content.

\textbf{Where and How is it used?}

\textit{String Creation:}
\begin{lstlisting}
s = "Python Programming"
\end{lstlisting}

\textit{Indexing:} Each character has a position number starting from 0; negative indexing counts from the end.
\begin{lstlisting}
print(s[0])    # 'P'
print(s[-1])   # 'g'
\end{lstlisting}

\textit{Slicing:} A portion of a string can be extracted using \texttt{[start:stop:step]}.
\begin{lstlisting}
print(s[0:6])   # 'Python'
print(s[::-1])  # reversed string
\end{lstlisting}

\textit{String Operations:} Concatenation (\texttt{+}), repetition (\texttt{*}), length (\texttt{len()}), etc.
\begin{lstlisting}
greet = "Hello " + "Siddhesh"
print(greet * 2)
print(len(greet))
\end{lstlisting}

%============================================
\subsection{Lists}

\textbf{What is it?} \\
A list is a data structure used to store multiple values in order inside a single variable, written using square brackets \texttt{[]}. Lists are mutable, meaning their contents can be changed.

\textbf{Why do we need it?} \\
Lists are needed to group and manage related data together -- for example, a list of marks or a list of names.

\textbf{Where and How is it used?}

\textit{Creating Lists:}
\begin{lstlisting}
fruits = ["Apple", "Banana", "Mango"]
\end{lstlisting}

\textit{Indexing:}
\begin{lstlisting}
print(fruits[0])    # 'Apple'
print(fruits[-1])   # 'Mango'
\end{lstlisting}

\textit{Slicing:}
\begin{lstlisting}
print(fruits[0:2])  # ['Apple', 'Banana']
\end{lstlisting}

\textit{Updating Elements:} Since a list is mutable, a value can be changed directly using its index.
\begin{lstlisting}
fruits[1] = "Orange"
\end{lstlisting}

\textit{Nested Lists:} A list can contain another list inside it.
\begin{lstlisting}
matrix = [[1, 2], [3, 4]]
print(matrix[0][1])   # 2
\end{lstlisting}

\textit{Basic List Methods:}
\begin{lstlisting}
numbers = [10, 20, 30]
numbers.append(40)    # add to end -> [10,20,30,40]
numbers.insert(1, 15) # add at a specific position
numbers.remove(20)    # delete a value
numbers.pop()         # remove last element
numbers.sort()        # ascending order
numbers.reverse()     # reverse the order
len(numbers)           # total number of elements
\end{lstlisting}

\begin{lstlisting}

print(a)

\end{lstlisting}
\textbf{Explanation:} Python allows swapping two variables in a single line using tuple unpacking: \texttt{a, b = b, a}. The right-hand side is evaluated first, then assigned to the left, so \texttt{a} becomes 20 and \texttt{b} becomes 10. No temporary variable is needed.

\subsection*{Experiment 5: Why input() Output Differs Before and After Conversion}
\begin{lstlisting}
age = input("Enter your age: ")
print(age + age)
age = int(age)
print(age + age)
# Why are the two outputs different?
\end{lstlisting}
\textbf{Explanation:} \texttt{input()} always returns a string. So the first \texttt{age + age} performs string concatenation (e.g. \texttt{"21" + "21"} gives \texttt{"2121"}). After converting with \texttt{int(age)}, the second \texttt{age + age} performs actual addition (e.g. \texttt{21 + 21 = 42}).
